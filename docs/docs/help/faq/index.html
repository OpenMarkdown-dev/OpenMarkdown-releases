FAQ

Is it free?

Section titled “Is it free?”

Yes, with no account. If it earns a place in your day, you can back it.

Does it include an AI?

Section titled “Does it include an AI?”

No. It works with the agent you already use: Claude Code, Codex, Gemini CLI, opencode, or any MCP client. See Connect your agent.

Can I watch my agent write a file live?

Section titled “Can I watch my agent write a file live?”

Yes. Open the file in OpenMarkdown. Whether the agent writes through the MCP tools or straight to disk, the page updates as it writes. Through the tools it can also scroll your view to the part it means (reveal).

Will my agent overwrite what I'm typing?

Section titled “Will my agent overwrite what I'm typing?”

No. Through the tools it edits one section at a time, and a write to a section you changed is refused until it reads your version. Changes it makes on disk are merged with your unsaved edits, and if both of you changed the same lines, ⌘Z brings yours back. See Co-edit.

Does it run on Windows and Linux?

Section titled “Does it run on Windows and Linux?”

Yes. Linux has everything macOS has except spellcheck and a few macOS-only settings. On Windows it is the editor without the agent features. See Platform support.

Where are my notes stored?

Section titled “Where are my notes stored?”

Where you put them: plain .md files in your own folders. New notes with no folder go to ~/OpenMarkdown. See Files, workspaces and Homes.

Will my files look the same in other apps?

Section titled “Will my files look the same in other apps?”

Yes. They are CommonMark with GitHub Flavored Markdown. The few writings OpenMarkdown adds (math, image sizes, @agent) degrade to readable text elsewhere: Markdown dialect.

How is it different from Obsidian, Typora or VS Code?

Section titled “How is it different from Obsidian, Typora or VS Code?”

Honest comparisons, including where they are better: openmarkdown.dev/compare.
