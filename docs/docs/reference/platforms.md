# Platform support

| | macOS | Linux | Windows |
| --- | --- | --- | --- |
| Download | `.dmg`, Apple silicon and Intel, signed and notarized | `.AppImage`, x64 | `-setup.exe`, x64 |
| Editor, tabs, Homes, find, outline | ✓ | ✓ | ✓ |
| Themes, languages, updates | ✓ | ✓ | ✓ |
| Spellcheck | ✓ | — | — |
| Warm start (menu bar / tray) | ✓ | ✓ | ✓ |
| Show in menu bar only | ✓ | — | — |
| Default app for `.md` from Settings | ✓ | — | set by the installer |
| `openmd` command-line tool | ✓ | ✓ | — |
| MCP server (`openmd mcp`) | ✓ | ✓ | — |
| `$EDITOR` / `$VISUAL` handoff | ✓ | ✓ | — |
| Sidebar terminal and intercom | ✓ | ✓ | — |
| Claude Code plugin | ✓ | ✓ | — |

On Windows, run the Linux build under [WSL](https://learn.microsoft.com/windows/wsl/install) to work with an agent.

Keyboard shortcuts on Windows and Linux use <kbd>Ctrl</kbd> where macOS uses <kbd>⌘</kbd>: [Keyboard shortcuts](/docs/reference/shortcuts/).
