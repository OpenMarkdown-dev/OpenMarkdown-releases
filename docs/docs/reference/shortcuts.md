# Keyboard shortcuts

The same list as the in-app cheat sheet (press <kbd>⌘/</kbd>). On Windows and Linux, <kbd>⌘</kbd> is <kbd>Ctrl</kbd>; both are shown. A dash means macOS only.

Inside the sidebar terminal, <kbd>⌃</kbd> combinations go to the terminal, except <kbd>⌃`</kbd>, which stays with the app.

## Navigation

| Action | macOS | Windows and Linux |
| --- | --- | --- |
| Next tab | <kbd>⌃⇥</kbd> or <kbd>⌥⌘→</kbd> | <kbd>Ctrl+⇥</kbd> or <kbd>Alt+Ctrl+→</kbd> |
| Previous tab | <kbd>⌃⇧⇥</kbd> or <kbd>⌥⌘←</kbd> | <kbd>Ctrl+Shift+⇥</kbd> or <kbd>Alt+Ctrl+←</kbd> |
| Reopen closed tab | <kbd>⇧⌘T</kbd> | <kbd>Shift+Ctrl+T</kbd> |
| Open palette | <kbd>⌘P</kbd> | <kbd>Ctrl+P</kbd> |
| Open command palette | <kbd>⇧⌘P</kbd> | <kbd>Shift+Ctrl+P</kbd> |
| Go to tab 1–9 | <kbd>⌘1</kbd> – <kbd>⌘9</kbd> | <kbd>Ctrl+1</kbd> – <kbd>Ctrl+9</kbd> |
