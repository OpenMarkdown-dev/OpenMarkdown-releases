# Outline, find and spellcheck

## Outline

Two outlines follow the note you are in and update as you type:

- **In the sidebar:** the Outline section lists every heading. Click one to scroll there.
- **In the margin:** a faint outline to the left of the text, on by default. It hides when the window is too narrow. Turn it off in **Settings → Appearance → Margin outline**.

To jump by typing instead, press <kbd>⌘P</kbd> and type `@`.

## Find and replace

<kbd>⌘F</kbd> opens find. It shows how many matches there are; <kbd>↩</kbd> goes to the next, <kbd>⇧↩</kbd> to the previous. A button makes it case-sensitive.

Replace is there in live preview and source mode. Reading mode is read-only, so it finds but does not replace.

Find matches plain text: there is no regular-expression or whole-word option.

## Spellcheck

macOS only, and off until you turn it on: **Settings → Appearance → Check spelling**. Misspelled words get a dotted red line; right-click one for suggestions. It uses the system's spellchecker, checks only your prose (not code or links), and works out each paragraph's language by itself.
