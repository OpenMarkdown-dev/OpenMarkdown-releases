# Themes and language

## Light and dark

**Settings → Appearance → Appearance**: Follow system, Light or Dark. Follow system switches with your OS, as it happens. You can also run **Theme: light** or **Theme: dark** from the command palette.

## Zoom

<kbd>⌘=</kbd> zooms in, <kbd>⌘-</kbd> zooms out, <kbd>⌘0</kbd> resets.

## Interface language

**Settings → Appearance → Language**: Follow system, English, Chinese or Japanese. A new language takes effect when the app restarts: press **Relaunch** in the panel (your notes are saved first), or it applies next time you open the app.

The language setting changes the app's menus and messages. Your notes can be in any language.
