EditorEnvironment

The editor environment: the capabilities that are not about one document — the color scheme, the clipboard, external links, spelling, host keys and the UI language. Give each editor its own with createEditorState({ environment }) (and change it later with editor.setEnvironment); configureEditorEnvironment sets the page's defaults, which every editor uses for the members it was not given. Per-document needs go through EditorHost instead.

Every member is optional: what the host leaves out is switched off quietly — no error, no notice, no fallback of the editor's own — except the two renderers, whose absence means the entry's built-in one. An editor mounted with no environment configured at all is light, English, editable, and has no copy, external-link, spelling or host-key behaviour.

colorScheme?

Section titled “colorScheme?”

optional colorScheme?: ColorSchemeSource | ColorScheme

Light or dark: a fixed "light" / "dark" (change it with editor.setEnvironment), or a live source — its value now, and a subscription to changes (returns the unsubscribe), which the editor follows while it is mounted.

language?

Section titled “language?”

optional language?: "zh" | "ja" | "ko" | "en"

The language of the editor's own UI words. Read whenever a word is drawn, so set it before the first editor mounts; already-drawn words do not redraw on a change. Left out, or not one the editor ships: English. Page-wide only: set it with configureEditorEnvironment (a per-editor environment has no language).

refusedLink?

Section titled “refusedLink?”

optional refusedLink?: (url, scheme) => unknown

The editor refused to follow a script-capable link (javascript: / vbscript: / data: …, however obfuscated); scheme is the scheme as a browser reads it. For telling the user only: the URL MUST NOT be opened. Absent: the refusal is silent.

renderDiagram?

Section titled “renderDiagram?”

optional renderDiagram?: DiagramRenderer

Your own diagram renderer, used for every ```mermaid fence in place of the editor's built-in Mermaid — for example your page's own copy of Mermaid, so the page loads one, or to have diagrams at all with an entry that carries no built-in one (/no-diagrams, /no-renderers). Left out: the entry's built-in renderer, if it has one; else the fence stays a code block. EditorStateOptions.diagrams: false turns diagrams off either way. See DiagramRenderer.

renderMath?

Section titled “renderMath?”

optional renderMath?: MathRenderer

Your own formula renderer, used for every $…$ and $$…$$ in place of the editor's built-in one (Temml) — to draw formulas the way the rest of your page does (MathJax, KaTeX), or to have formulas at all with an entry that carries no built-in renderer (/no-renderers). Left out: the entry's built-in renderer, if it has one; else formulas show as their TeX. See MathRenderer.

spell?

Section titled “spell?”

optional spell?: SpellService

The spell-checking service behind the editor's own squiggles and suggestions. Absent: no spell checking.
